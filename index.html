A free arena shooter with rocket jumps, a grappling hook and ranked 1v1. Written from scratch in C++ for the lowest latency and the steadiest frame rate.

The game

MovementDash, grapple, rocket jump, bunny hop and climb ladders. Physics runs in fixed 1 ms steps, so movement feels the same at any frame rate.

Netcode1000 Hz servers with client prediction, lag compensation and delta-compressed snapshots. A cheap VPS can host it.

Built for frame timeThe renderer is judged by its 1% and 0.1% lows, not its average. F3 shows them live. Low-latency present modes and optional anti-aliasing (off by default) are included.

Ranked 1v1Three ladders: Vanilla, Laser Vampire and Instagib, each with its own symmetric maps and rating.

Map editorBuilt into the game. Edit with friends over the network, then vote to play the result.

HostingHost from the menu, or run a dedicated Linux server that updates itself.

Make it yours

Every part of the HUD and the controls can be changed, saved and shared.

  • HUD widgets: show health, speed, dash, hook, fps, fps min, ping, loss, enemies or teammates alive, K/D, score or tick rate. Each can be a number, a bar, a colour-graded bar, an icon whose opacity follows the value, or an icon with a bar.
  • Verbose HUD: clock, version, fps and fps min, speed, ping, loss, tick and snapshot rate, players alive, map, mode and K/D in the top right.
  • Control scripts: for opposite movement keys, choose cancel, last pressed wins (snap tap) or first pressed wins. Alt-fire can be hold or toggle.
  • Import / export: HUD layouts and control profiles copy to the clipboard and save as files you can share.
  • Mode rules: load a different HUD or control profile automatically in each mode.
  • Five player models: Standard, Heavy, Scout, Robot and Knight. They're cosmetic with identical hitboxes, and everyone sees yours.
  • Five sound packs: Standard, Arcade, Heavy, Retro and Soft. Other players hear your guns and hurt sounds in your pack. Every pack is normalised to the same loudness.

Ranked is the same for everyone. Ranked matches always use the default model, the default HUD and no control scripts or mode rules, so nobody has an advantage. Your own key binds and sound pack still apply.

Run a server

To host from the game, choose Host game. To run a 24/7 server on a Linux machine (a free cloud VM is enough), clone the repo and run:

sh tools/server/install.sh --public --name "my server"
# ranked:  --ranked --variant vanilla --map temple

The server starts on boot and restarts if it crashes. It installs new versions when nobody is in a match.
