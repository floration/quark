SECTION 04 // HOST

Run a server

In the game: Host game, pick a mode and a map, start. For a 24/7 server on a Linux machine (a free cloud VM works), clone the repo, then:

sh tools/server/install.sh --public --name "my server"
# ranked:  --ranked --variant vanilla --map temple

It starts on boot, restarts if it crashes, and installs new versions by itself once nobody is mid-match.
