# quark 0.15.0

## Vote to change map or mode
- Anyone in a server can call a vote to switch map or mode: pause menu → **VOTE...** → **MODE...** or **MAP...**, then pick from the full list.
- A majority of the human players decides. When it passes, the server switches like a host change does, and everyone reloads into the new map.
- The host can still change map or mode directly, without a vote.
- Dedicated servers accept the same vote from chat: `/callvote map <name> [mode]` or `/callvote mode <mode>`.
