# 1.18.1

A fix for hosting on Windows. Network protocol unchanged: 1.17.0, 1.18.0 and 1.18.1 games and servers play together.

## Fixes
- **STOP HOSTING no longer closes the game** (Windows). Ending a hosted game with bots in it crashed the game without a message; it now returns to the main menu. The same crash hit BACK TO EDITOR after a test map, ending vs bots or a time trial, and a dropped connection while hosting. 1.18.0 fixed only half of this.
