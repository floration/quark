# 0.22.0

- **Edit maps together.** In the map editor, **HOST EDIT SESSION** hosts the open map with your host settings (port, server list). Others join from the Join screen like any game and land straight in the editor.
  - Everyone can build. Each edit goes through the server, so all copies stay identical. Anyone who falls out of sync, or joins late, re-downloads the current map automatically.
  - You see the other editors as floating cameras with their names.
  - Undo (Ctrl+Z) undoes your own edits, not anyone else's.
- **The host's map is always autosaved**: every 5 seconds while it has changes, and when the session ends.
- **Players who aren't the host are asked whether to save their own copy** when they leave or the server closes. They can also click SAVE A COPY at any time.
- **Switch between editing and playing.**
  - The host clicks **PLAY MODE** to save and start a normal match on the map, in its "built for" mode if it supports that, otherwise FFA.
  - **EDIT MODE** in the ESC menu brings everyone back into the editor, starting where they were standing.
  - Server console: `editmode on` / `editmode off`.
- Chat, votes and other text commands now send several at once instead of one per round trip, so bursts (like holding an arrow key in the editor) don't lag.
- The network protocol changed to version 14, so servers and clients must both be on 0.22.0.
