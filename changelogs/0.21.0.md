# 0.21.0

- **Map editor** (main menu → MAP EDITOR). Fly around and place boxes in base, accent or wallbang material, plus spawns (team A, team B, any, race), lights, bomb sites, a hill, race checkpoints and payload path points. Everything snaps to a grid of 0.25 to 4 m.
  - **Controls:** hold right mouse to look and use WASD to fly. Click to select. Arrows and PgUp/PgDn move the selection, Shift+arrows grow it, Ctrl+arrows shrink it. M changes material or team. Ctrl+D duplicates, Del deletes, Ctrl+Z undoes, Ctrl+S saves.
  - **BAKE LIGHT** previews the real lighting.
  - **TEST** saves the map and starts a private game on it. Leaving that game takes you back to the editor.
  - The panel shows which modes the map can be played as.
  - Maps save to `maps/<name>.qmap`. Use your own name: the built-in maps are replaced by updates.
- **Automatic map download.** When you join a server running a map you don't have, or a different version of one you have, the game downloads it from the server while connecting. Downloads are kept in `maps/downloads/` and reused next time.
- **Maps reload without restarting.**
  - The host's pause menu has **RELOAD MAP**, which re-reads the current map file and sends any changes to everyone. The server console command is `reload`.
  - New or edited map files show up in the map lists right away.
- The network protocol changed to version 13, so servers and clients must both be on 0.21.0.
