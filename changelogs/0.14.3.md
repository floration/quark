# quark 0.14.3

## Mouse sensitivity in cm/360
- Settings has a **CM/360** slider under sensitivity, plus a **DPI** button (click to cycle: 400, 800, 1000, 1200, 1600, 2400, 3200, 6400).
- Dragging either slider updates the other. Set your mouse's DPI and type in, or drag to, the cm/360 you use in other games.
- Sensitivity uses the same scale as CS and Quake (0.022° per mouse count), so you can also copy your CS sensitivity number directly. The zoomed sensitivity scales with field of view, so scoping feels the same.
