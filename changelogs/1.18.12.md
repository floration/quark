# 1.18.12

A model modding update: ranked games only show the shipped models, more of the game's models can be replaced, and replacement models made in the new model editor look exactly like the built-in ones. Gameplay, the network protocol and demos are unchanged: 1.18.12 plays with 1.18.7 and newer (protocol 43).

## Models
- **Ranked is fair again.** Ranked matches and time trials now ignore the model files in your own overrides folder: everyone playing there sees the shipped models. Before, your own files applied in ranked too, so someone could make enemies huge or neon for themselves. Casual games, and spectating a ranked match, still show your own models.
- **More models can be replaced**: the arms, the bomb (on a carrier's back and on the ground), the payload cart and the checkpoint gates are now models like the players and weapons (`models/prop/` in the overrides folder). They look exactly as before.
- **Replacement models look like the built-in ones.** A model made in the model editor is drawn the same way as the game's own: with outlines, crouching per box, team colours and face plates hidden in first person. A broken model file is ignored and the default is kept.

## Tools
- **Model editor (for modders and the developer):** `tools/model_editor` builds a local page that shows every model the way the game draws it, lets you edit it box by box or import a .glb, and exports it into the overrides folder.
