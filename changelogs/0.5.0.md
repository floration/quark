# quark 0.5.0

## Launcher
- Install options in the launcher:
  - Windows: Desktop icon, Start Menu entry, and Installed Programs (shows up in Settings > Apps / Programs and Features with its version, size and an Uninstall button).
  - Linux: Desktop icon and app menu entry.
  - macOS: Desktop icon and Applications folder entry.
- Uninstall button (click twice to confirm): removes shortcuts, the programs entry and all game files.
- The launcher now installs itself to a fixed per-user folder (%LOCALAPPDATA%\quark on Windows, ~/.local/share/quark on Linux, ~/Library/Application Support/quark on macOS), so shortcuts keep working even if you delete the file you downloaded. The game is kept in a "game" folder inside it.
- No administrator rights needed: everything is per user.

## Other
- quark now has an icon (game and launcher on Windows, shortcuts on Linux).
