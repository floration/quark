# quark 0.14.1

## Menus
- **Pause menu:** a single **VOTE...** button opens a list of everything you can vote on: start the match (in warmup), balance bots on or off, and bot difficulty.
- **Map and mode changes (host):** **CHANGE MODE** and **CHANGE MAP** open the full list of modes or maps, instead of stepping to the next one.
- **Option buttons** no longer have a "LABEL:" prefix. They just show the setting, like "BORDERLESS FULLSCREEN", "LOW LATENCY ULTRA" or "UNLIMITED FPS", so long values no longer overflow.
- **Crosshair customization** is in Settings → **CROSSHAIR**, next to CONTROLS. It arrived in 0.14.0.

## Launcher
- **Version picker:** a scrollable list beside the changelog (mouse wheel or scrollbar) instead of arrows. The installed version is marked with `*`.
- **Window icon:** on Windows, the window and taskbar now show the quark icon instead of the default one.
