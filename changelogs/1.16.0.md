# 1.16.0

- **macOS is back**: Mac packages and launcher build again.
- **Rocket direct hits deal 50**, and **sniper headshots deal 50**.
- **Lifetime K / D has its own scoreboard column** that counts up live during the match. It's sent to the server when the game ends.
- **Sound mods without rebuilding**: put WAV files in `<game folder>/mods/sounds/<kit or all>/<SOUND>.wav` and they load at startup. Each package includes a README explaining the layout.
- **Asset Studio**: a page that lists every default sound, model and map, with players and a 3D viewer. Replacements uploaded there become the defaults in the next update.
