# 0.24.1

- **Three ranked ladders, each with its own rating.** Ranked is always 1v1, played on one of three rulesets:
  - **VANILLA**: every weapon
  - **LASER VAMPIRE**: lasers only, damage heals you
  - **INSTAGIB**: snipers, any hit kills
- **Hosting:** pick the ruleset in the Host screen's 1v1 ruleset as usual. Any other ruleset falls back to Vanilla. The server list shows the ladder, for example `[RANKED LASER VAMPIRE]`. A dedicated server picks its ladder with `--ranked --variant vampire`.
- **Ratings:** the scoreboard shows ratings for the ladder being played. Winning on one ladder never touches your other two.
- Matches aren't rated after a vote switches the server to a ruleset that isn't a ladder.
- **Server owners:** this needs the updated `tools/master/worker.js` (the database tables are unchanged).
