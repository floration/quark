# 1.18.10

A font update: the game's text is now **Rubik Bold**, and the new **SETTINGS > FONT** page lets you pick another one, including fonts styled after other games and any font you add yourself. It plays with 1.18.7 and 1.18.9 games and servers (same network protocol).

## Fonts
- **Rubik Bold is the new UI font** (menus, HUD, chat, scoreboard, editor; the console stays monospaced). It's the same font as the logo, launcher and website title, and about as wide as Work Sans Bold, so every layout fits as before.
- **SETTINGS > FONT** (the FONT button beside BACK, in the menus and in game): pick **RUBIK**, **WORK SANS** (the font of 1.17 - 1.18), **QUARK CLASSIC** (the original pixel font) or a font styled after a game: **OVERWATCH**, **COCAINE DIESEL**, **QUAKE**, **HALF-LIFE 2**, **TF2**, **TF2 SECONDARY** and **APEX LEGENDS**. The text changes at once, and your pick is kept.
- The game-styled entries use the closest free font, bundled with the game. If you have the real one, it's used instead: Windows' Verdana for Half-Life 2, a Steam install of TF2 or Quake, or the real font files put in `mods/fonts` (the names are in `mods/fonts/README.txt`). Those files are only read on your computer, never shipped.
- **Your own fonts**: put any `.ttf` / `.otf` in the game folder's `mods/fonts` (OPEN FOLDER on the FONT page) and press REFRESH to pick it. If a picked font is gone at the next start, the game goes back to Rubik and tells you.
- Asset overrides: `fonts/Rubik.*` now replaces the default font; `fonts/WorkSans.*` replaces only the WORK SANS entry. Each bundled look-alike can be replaced by its own file name.
- The game download is about 0.5 MB bigger (the built-in fonts).
