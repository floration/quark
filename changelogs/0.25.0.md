# 0.25.0

- **RANKED in the mode picker.** Host → Mode now has a **RANKED** choice holding the three ladders: VANILLA, LASER VAMPIRE and INSTAGIB. Picking any other mode turns ranked off. The separate RANKED toggle is gone.
- **Ranked only runs on official maps.**
  - A map counts as official when it's a shipped map, checked by both name and file contents.
  - The map list greys out other maps, and a ranked server refuses to start on one or switch to one.
  - Each player's game also checks: on a map that isn't official, it doesn't report the result, so the match is never rated.
  - Map editing is off on ranked servers.
- **Always visible in a ranked game:** a gold bar and a RANKED tag on the top panel, which reads "RANKED 1V1 - <LADDER>".
- **Type any value into a slider:** click the number, type a value, then Enter (or click elsewhere) to apply it. Esc cancels. The number gets an underline on hover.
- **Knife:** only the beam from your hand out to the tip now; the side-to-side swipe is gone.
