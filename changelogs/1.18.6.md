# 1.18.6

A sound modding update: replacement sounds can now keep the volume you set for them.

## Sounds
- **Your own volume for replacement sounds.** The game normally plays a replacement sound or voice line at the loudness of the sound it replaces, so every sound pack stays fair. A file listed in `sound-levels.txt` now keeps its own loudness instead (it is only turned down if it would clip). This works for the overrides folder and for `mods/sounds/`.
- **Sound editor (for modders and the developer):** `tools/sound_editor` builds a local page to hear every pack's sounds and every voice line, try them in gameplay scenes, trim and filter them, set groups to the same loudness, and export them into the overrides folder.
