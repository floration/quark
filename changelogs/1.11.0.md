# Quark 1.11.0

## Demos
- Record what you see: ESC > RECORD DEMO, then ESC > STOP RECORDING. Demos go in the `demos` folder, named after the map, mode and time.
- Watch them from MAIN MENU > DEMOS (newest first), or with `quark --demo <file>`. You see through the recorder's eyes, with everyone else, the chat, kill feed and HUD as they happened. ESC > STOP DEMO goes back to the list.
- A demo carries its map, including your own and edited maps, so it plays anywhere on the same version. It records at 60 Hz, about 15-20 kB a second.

## Key overlay
- A new HUD element: W A S D, mouse buttons, jump, crouch, dash and hook light up while you hold them.
- It's part of the verbose HUD (Settings > HUD > VERBOSE INFO). Move, size, recolour or hide it in the HUD layout editor (KEY OVERLAY).

## Scoreboard
- New ACC column in every mode: the share of your shots that hit an enemy (hitscan and projectiles; a rocket counts as a hit if its blast damages anyone).

## Server freeze fix (why 1.8.0 and 1.10.0 never released)
- A server catching up on missed ticks could get stuck forever if each tick took longer than real time. It only checked for "fell far behind" before catching up, never during. The release builds froze this way in the time trial test on GitHub's slower machines. A busy real server could freeze the same way. It now catches up at most 20 ticks at a time, then skips ahead and gets back to the network.
- Tests made robust on slow machines:
  - The bot aim test's target strafes and turns at the edges, instead of teleporting back to the middle. Each level is measured for 25 s.
  - The multi point test waits for the round to start instead of a fixed time.
- 1.11.0 includes everything from 1.9.0 and 1.10.0.
