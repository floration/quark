# 1.15.0

(No macOS build this release.)

- **Custom modes: MOVEMENT page.** Every movement setting can be scaled in a custom mode: crouch speed, ground acceleration and friction, air acceleration / strafe cap / overstrafe brake / air control, step height, dash speed / length / exit speeds / cooldown, bhop bounce, grapple range / pull / top speed / gravity / cooldown, ladder speeds. Everyone in the game moves by the same numbers.
- **Lifetime kills and deaths.** Your kills and deaths add up across every session, version and mode; the scoreboard shows everyone's TOTAL K / D (outside ranked).
- MOUTH sound kit: each sound trimmed to a sensible length (one footstep, not several).
