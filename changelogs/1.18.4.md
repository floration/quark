# 1.18.4

A small server fix. Network protocol unchanged (42).

## Servers
- A big reliable message, such as a long chat line, a ranked ticket or a map edit, can no longer get stuck waiting while a crowded snapshot has no room for it. The oldest one now always gets its room, and that snapshot carries fewer projectiles instead. This is the server half of the fix for occasionally lost kill-feed lines, chat and names. The client half comes with the next game update.
