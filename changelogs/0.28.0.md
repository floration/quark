# 0.28.0

## Leaderboard
- New **LEADERBOARD** screen in the main menu, with the top 20 for each ranked ladder (vanilla, vampire, instagib) and your own rating.
- The website has a live leaderboard section with the top 10 for each ladder.
- Ranked reports now include player names. Players appear after 3 ranked games.

## Map pool
- There are 13 maps now. Sprint and the old Duel map are retired.
- Ranked maps:
  - Temple: vanilla.
  - Furnace: vampire.
  - Gantry: instagib.
  - Anvil: all three ladders.
- All ranked maps are point-symmetric and have mirrored spawns.
- Ranked can only run on a ranked map for its ladder. Votes and map commands enforce this.
- Arena, Foundry and Colosseum support every mode.
- Mode maps: Depot (bomb), Summit (koth), Tug (neutral payload), Railyard (payload), Harbor (FFA) and Crucible (duel).
- Railyard and Tug got tracks, signal gantries and containers. Decorations on every map are now placed in symmetric pairs.

## Duel
- 30 Duel rulesets. Each one sets its own weapons, health, player size, movement and damage, and some add health regen.
- A Duel match is now first to 11.
