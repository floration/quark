# 0.29.0

## Map looks
- Every map now has its own colors (walls, trim, metal, glow and sky). For example: Furnace is blood-red, Harbor is docks at sunset, Temple is sandstone and gold, Summit is ice blue.
- There are two new surface materials, **metal** and **glow** (lit trim). Both are in the map editor, so you can use them on your own maps.
- New details on every map:
  - Glow lines along the walls.
  - Emblems on the end walls.
  - Lamps hanging under the roof beams.
  - Floor inlays.
  - Capped cover blocks with glow bands.
  - Metal catwalks, pipes and containers.
- Rendering:
  - Surfaces have subtle panel detail.
  - Walls are darker near the floor.
  - Colors use filmic tone mapping.
  - The sky has a gradient and a sun glow.
  - The cost is a few shader instructions; the sky only shades pixels nothing else covers.

## Maps renamed
- No map is named after a game mode any more: **Arena** is now **Bastion**, and **Tug** is now **Canal**. Old configs and votes that use the old names still work.

## Votes
- A refused map vote now says why: the server doesn't have that map (it may be on an older version), or the map can't run that mode.
- A test now calls a vote for every map and mode pair, to make sure none are refused by mistake.
