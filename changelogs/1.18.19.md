# 1.18.19

Custom modes can now change the weapons themselves, not just scale them. The standard weapons and every built-in mode are unchanged.

## Custom modes
- **Weapon sets**: a custom mode can name a weapon set (`weaponset=<name>`, a file in `custom_weapons/`) that changes any weapon's numbers: damage, headshot damage, fire rate, range, spread and scope, projectile speed, drop and lifetime, splash, direct-hit damage, self damage, wallbang damage, knockback, damage falloff with distance, and every alt fire (the rocket lob, knife and syringe throws, shotgun bounces, the laser pull, the rifle scope, the bubble stream, stickies). A set can also rename a weapon and add its own rules for what a hit or a kill does (for example double damage on airborne players, or health back for a kill).
- Players joining a server that plays a set get it automatically, so their shots, spread and projectiles match the server's. A set that is missing, broken or too big falls back to the standard weapons and says why.
- **Where it runs**: games you host with a custom mode (unranked). Ranked matches and time trials always play the standard weapons.

## Weapons editor (for weapon makers; not in the game download)
- A new local page for making weapon sets: `tools/weapon_editor` (http://127.0.0.1:8773/), also the Weapons Editor tab of the Quark Project app. Edit each weapon's numbers, see a values table of damage, shots and time to kill and DPS (body and head, every alt fire) against the standard, compare with weapons from 19 other games, write hit / kill rules as code, blocks or a graph, test against still and moving targets on a range or any map, and watch or batch-run bot fights with the set. One click writes a custom mode that plays it.
