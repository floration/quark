# quark 0.1.0

First playable build.

- Custom C++ engine: OpenGL 3.3 renderer, custom UDP netcode, no game engine dependencies
- Flat grey world with black outlines on every edge, pre-baked lighting (soft sun shadows, sky occlusion, light bounce)
- Real-time shadows for players and projectiles
- Multiplayer: host from the game or run quark_server; automatic port forwarding (UPnP); LAN server list
- Client-side prediction, smooth interpolation, lag-compensated hit detection
- Game modes: VS, Bomb, Race, King of the Hill, Payload, Free for All
- Maps: arena (all team modes + FFA), sprint (race)
- F3 performance overlay (average, 1% low, 0.1% low FPS)
- Placeholder weapons (rifle, rocket, knife) and movement until the final designs
- Launcher that downloads and installs updates automatically
