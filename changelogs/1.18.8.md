# 1.18.8

A behind-the-scenes update to how builds are checked. Nothing changes in the game, and it plays with 1.18.7.

- Automated builds now check only that the game builds and packages on Windows, Linux and macOS. The gameplay and menu tests run on the developers' machines before every update, and every testing build is played by hand before it reaches production, so builds come out faster.
- The deep memory-safety checks (sanitizers and fuzzers) now run only on the build marked as the final test before a release.
