# 1.18.0

A latency and performance update: less time from your mouse to the screen, lower audio latency on Windows, and cheaper servers. Network protocol unchanged: 1.17.0 and 1.18.0 games and servers play together.

## Display and input
- **Latent Sync** (Windows, the new default PRESENT setting): no tearing, at nearly no-vsync latency. The game shows one frame per refresh and flips it just as the monitor's blank begins, with the mouse read as late as the frame's own render time allows. It times itself to your PC; if your PC can't keep up with the refresh rate, it runs unsynced (it tears instead of stuttering) until it can. A TEAR LINE OFFSET slider fine-tunes it. Linux and macOS default to NO VSYNC.
- **The mouse is read again just before the world is drawn** (late latch), and the HUD and player shadows are now built before that read, so less sits between your mouse and the screen. Your weapon model always follows your aim exactly.
- **Raw mouse input on its own thread** (Windows): an 8000 Hz mouse no longer costs frame time, and the cursor is held still while the game has it.
- **LOW LATENCY ULTRA is paced like NVIDIA Reflex**: each frame starts just in time for the GPU, so ULTRA no longer costs fps.
- **Vsync in a window or borderless** uses the driver's vsync instead of a wait for the desktop compositor: one refresh less delay (7 ms at 144 Hz).
- **Your own position is drawn as of now**, not one server tick behind.
- **MAX FPS is a slider**: drag or type any cap (0 = unlimited); right-click sets it to your screen's refresh rate (subtract a few for G-Sync / FreeSync).
- **GPU MAX CLOCKS** (Windows, NVIDIA): sets "Prefer maximum performance" for the game in the NVIDIA driver, so a GPU idle half of every frame doesn't clock down. From the next start.

## Audio
- **Windows sound goes through WASAPI** with 10 ms queued (was 30 ms through WinMM).
- **EXCLUSIVE AUDIO** (Windows): the sound device for the game alone, about 3 ms of buffering; other programs are silent while it's on.

## Performance overlay
- **F3 shows a mouse-to-photon graph**: every part of a frame as a bar on one time line in microseconds, from the mouse's report to the light leaving the screen at the crosshair (measured CPU and GPU times; the display's part worked out from its refresh rate and, with vsync, its real blank timing).
- **F4 shows only the mouse-to-photon number.** VOTE START moved from F4 to F5 (your saved key moves too).

## Servers and performance
- **Server ticks are 16-33% cheaper on average and the worst ticks less than half as long**, with exactly the same results. Hosted servers keep their 1000 Hz on Windows 11 when the window is minimised.
- **Fewer frame-time spikes**: no memory allocations per frame in a match, fewer rays per player, cheaper text, and a shadow pass that only covers where players are.
- **Faster map loads** on big maps (the light bake's buried-face test looks only at nearby brushes), and leaving during a load no longer freezes the window.

## Fixes
- A crash when a hosted game's server thread ended (memory freed twice on Windows).
- Remote players are drawn 7-16 ms closer to the present (frame time no longer counted as network jitter).
- Held fire keeps the server's rhythm: sounds and tracers no longer drift late over a burst. The weapon kick recovers at the same speed at any frame rate.
- EXCLUSIVE AUDIO no longer runs off the bottom of the settings screen.
