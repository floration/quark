# 1.18.30

Servers no longer lower their tick rate because of one short hitch on the host machine. The physics editor's game comparison gains 12 more games. No protocol change: 1.18.30 plays with 1.18.22 and newer games and servers (protocol 44).

- **Steadier tick rate on servers.** A single short pause on the host (common on cloud machines) used to be enough to drop a server from 1000 Hz to 500 Hz at the next break. Now late ticks must show up in two 3-second checks in a row before the rate steps down. Heavy load, bandwidth trouble and lag for most players still lower it straight away. The server log says `late ticks in one window (...), waiting for a second` when it holds off, and `status` shows it too.
- **Physics editor: 12 more games to compare.** The Values tab's game picker now has Quake Live, Quake Champions, Reflex, UT2004, UT3, Halo 3, Halo Reach, DOOM Eternal, CoD4, Fortnite, Portal 2 and CS 1.6 as competitive servers run it. Apex, Overwatch 2, UT99 and Minecraft gain the values they were missing. Each value says where it came from and whether it is exact, measured or estimated.
