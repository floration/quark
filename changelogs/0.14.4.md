# quark 0.14.4

## Internet server list fixes
- **Your own server shows up.** Most routers can't reach their own public IP from inside the network, so your own listed server never answered. The game now recognizes your own server and asks it locally instead.
- **Silent servers stay visible.** A listed server that doesn't answer still appears after a couple of seconds as "NO RESPONSE (PORT NOT OPEN?)", and you can click it to try connecting anyway. Before, it was hidden.
- **More reliable queries:** each listed server is asked up to 3 times, so a single dropped packet no longer hides it.
