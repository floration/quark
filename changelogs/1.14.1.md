# 1.14.1

- Run speed back to **8 m/s**, with quicker acceleration (you reach full speed sooner).
- Explosions are **25% louder**.
- New sound kit **MOUTH** (recorded by the owner) replaces WOODEN.
- Make your own sound kits: drop files into `assets/sfx/custom/<kit>/` (list of every sound in the README there).
- **Orbital**: windows in the hull looking out into space - a ringed planet, moons and stars.
- Crown letters (Q, LG, I, R) are part of the crown model.
- Queue menu fits on smaller screens (two columns).
- The launcher always adds a desktop icon and a start menu entry (the toggles are gone).
- Score box no longer overlaps its text on small screens; notices show on the main menu; the leaderboard fits 4:3 screens.
- Tests run about 3x faster.
