# 1.18.11

Bots can now play custom "brains". Default bots play exactly as before.

## Bots
- **Bot brains**: everything a bot decides is now data: its reaction times, aim and movement numbers, the % chances to jump, dash, grapple or strafe, its weapon choice by range, the curves behind them, and which objective it goes for in each mode. The built-in brain is today's bot, unchanged.
- **Your own brains**: put a `.qbrain` file in your user data folder's `bots\` (Windows `%APPDATA%\quark\bots\`) and add a bot that plays it with `addbot [a|b] [skill] brain=<name>`. The local bot editor (`tools/bot_editor`) writes these files. `brain=default` forces the built-in bot.
- A bot playing a brain file shows it when it joins, e.g. `BOT ANNA (EXPERT, mybrain#1a2b3c4d) joined`. A broken file is refused with the line and column of the error.

## Servers
- Dedicated servers: `--botbrain <name>` makes every bot the server adds play that brain. Brains work on local, listen and unranked servers; ranked and time trial never load them.
