# 0.37.0

Customisation before 1.0: player models, sound packs, a scriptable HUD and control scripts.

- **Player models**: STANDARD, HEAVY, SCOUT, ROBOT and KNIGHT (Settings → MODEL). Purely cosmetic, same hitbox, and everyone sees yours. Bots pick one at random.
- **Sound packs**: STANDARD, ARCADE, HEAVY, RETRO and SOFT (Settings → SFX).
- **Verbose HUD** (HUD LAYOUT → VERBOSE INFO): a dense block in the top right showing clock, version, FPS, FPS min over the last second, speed, ping, loss, tick / snapshot rate, enemies and teammates alive, round time, map, mode and K / D.
- **Custom HUD widgets** (HUD LAYOUT → WIDGET EDITOR):
  - Show any game value as:
    - a number (optionally colour-graded);
    - a bar;
    - a colour-graded bar;
    - an icon whose opacity follows the value;
    - an icon + bar.
  - Values available: health, speed, dash, hook, fps, fps min, ping, loss, time, enemies, teammates, kills, deaths, score and tick rate.
  - **Editing**:
    - Add, duplicate or delete widgets.
    - Drag them anywhere; they snap to the nearest corner so layouts survive resolution changes.
    - Pick the value from a dropdown, then set style, icon, size, bar size, max, colours and label.
  - Layouts are saved in `hud.cfg`, which you can also edit by hand; changes reload live.
- **Import / export**, for both HUD layouts and controls:
  - Export copies the layout to the clipboard and also saves a file in `huds/` or `controls/`.
  - Import uses the clipboard when it holds a valid layout; otherwise it lets you pick a file from the folder.
  - FOLDER opens the folder.
- **Control scripts** (Controls):
  - Opposite keys (SOCD): cancel out (default), last pressed wins (snap tap / null binds), or first pressed wins.
  - Alt-fire hold or toggle.
- **Mode rules**: choose a HUD layout and a controls profile that load automatically in a given mode (for example a minimal HUD in FFA and toggle-scope binds in 1v1). Your defaults come back when you leave that mode.
- **Ranked fairness**: ranked always uses the default HUD and no control scripts. Widgets, verbose info, SOCD, alt toggle and mode rules are all ignored there, and the ranked screens say so.
