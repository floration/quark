# quark 1.16.1

Security fixes.

- **Dedicated servers update again**: auto-update now waits only for the platforms this release actually ships, not for a fixed windows/linux/macos list.
- **Safer launcher installs**: an update is unpacked into a separate folder and swapped in only when complete, so an interrupted or broken download never leaves a half-updated game. Archive paths and sizes are checked strictly, and closing the launcher during a download no longer risks a crash.
- **No shell commands**: on Linux and macOS, the launcher and game run curl, xdg-open, open and gio directly instead of through a shell. Odd folder names (like `it's`) can no longer break or hijack them. Ranked secrets are no longer passed on curl's command line.
- **Modern TLS only** on Windows: TLS 1.2 and 1.3.
- **Server list**: servers get a token on their first announce. A server can only list or remove its own address, so nobody else can de-list servers. Server list and ranked endpoints are now rate-limited, and lifetime stats are capped per hour.
- **Discord bot**: server and player names are shown without links or formatting. At most 15 live server channels exist, and a server must be up for 2 minutes before it gets one.
- **Release builds** run with read-only repository access; only the release and website steps can write.
