# quark 0.16.1

## Launcher fixes
- **No more launchers multiplying in the background.** If the launcher couldn't copy itself into the program folder (for example because another launcher was already running), it handed off to itself, and that copy did the same, over and over. It now never hands off to itself, and a launcher started by a hand-off never hands off again.
- **Only one launcher runs at a time.** Starting it again just brings the open one to the front.
- **No more duplicate files in the program folder.** The installed launcher always has the same name (`quark_launcher.exe`), whatever the download was called, such as "quark_launcher (1).exe". Leftover copies from older versions are deleted.

If you still have extra launchers running from the old version, end them in Task Manager or restart once. 0.16.1 cleans up the rest.
