HUD Editor
The game is running. Widgets (hud.cfg) show in it within a second; built-in element changes (quark.cfg) are read when the game starts, and the game writes quark.cfg back when its settings change, so close it before saving those.

Drag anything to move it; the mouse wheel sizes the selection; arrow keys nudge it (Shift: 10). Built-in shapes are close to the game's, not exact; the weapon and grapple launcher are outlines of where the models sit. Check in game with Settings > HUD.

HUD profiles live in the game's huds/ folder (Settings > HUD > widgets EXPORT writes them; per-mode HUD rules pick one). Opening one loads its widgets here; Save then writes hud.cfg.

hud.cfg as it will be written. Edit and press Apply to read it back.
