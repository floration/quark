Testing channel

Play the next version first

Testing builds are made from the testing branch every time something changes, well before it reaches a production release. They're signed like every release. Expect bugs: finding them is the point.

Join the testing channel

  1. Install the launcher for your system from the download section, if you don't have it yet.
  2. Switch the channel. In the launcher, click CHANNEL: PRODUCTION. It changes to CHANNEL: TESTING and the list shows testing builds.
  3. Install the newest testing build from the list and play. The launcher checks its signature first, like any update.
  4. Going back is the same button: click CHANNEL: TESTING to return to PRODUCTION, then install the latest production version. Your settings, binds, demos and maps live in your user folder and are kept either way.

Testing servers

Every dedicated server box also runs a second server named [TESTING]. It follows the newest testing build, so testers can play together as soon as a build is out.

Ranked on testing servers is never rated. You can play ranked matches there to try things out, but the scores don't count: no rating changes and no leaderboard places.

What to test

Whatever changed in the newest build. Its notes list every change; try each one, and play normally too: the bugs nobody expected are the ones that matter.

Report a bug

Post in #testing-updates on Discord or open a GitHub issue. Please include:

  • The build number from the bottom-left corner of the main menu (for example 1.18.0-test.42).
  • Your system: Windows, Linux or macOS, and its version.
  • Steps to make it happen again, and what you expected instead.
  • A demo or a screenshot if you can (F12 takes a screenshot; demos are under DEMOS in the main menu).
