How ranking works

Placement first

You appear on a ladder after 5 rated matches. Until then your account is provisional, and your results only count toward other players once you've placed.

A cautious rating

Your rating is a careful estimate of your skill: it climbs as you win and as the system grows sure of you. Each ladder is rated on its own.

Only real matches count

A match is rated only if the server opened it with the ranking server and both sides report the same result. Matches on testing servers never count.

Same game for everyone

Ranked games use the default model, HUD, controls and 10 ms interpolation. Leaving a live ranked match first loses it.

Viaduct time trial

Start a time trial from the main menu. The server that saw your run reports it, and your best time is the one on the board.

Find a match

Queue from the game's main menu or from the Discord panel. The counts above show who's waiting.
