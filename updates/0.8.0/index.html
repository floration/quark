Update

quark 0.8.0

Everything that changed in this version, and why.

The full notes for this version are its short notes: that was all that was written then.

Bots

  • Play vs Bots (main menu): pick a mode, map, difficulty, and how many enemy and teammate bots. Runs a private local server, no port forwarding needed.
  • Four difficulties:
    • Beginner: slow to react (0.7 s), shaky aim, rifle only.
    • Intermediate: 0.4 s reactions, strafes while fighting, picks shotgun/rifle by range.
    • Advanced: 0.25 s reactions, bunny hops, dashes, uses rockets (aimed at your feet), crossbow and sniper, leads moving targets.
    • Expert: 0.15 s reactions, tight aim, fast turning.
  • Bots play every mode: they capture the hill, push or block the payload, carry and plant the bomb (and keep going for the site while shooting), defuse, and run races.
  • Bots find their way around with a navigation graph built automatically from the map's blocks (they plan jumps between platforms), so every map, including new ones, supports bots.
  • Bots use exactly the same movement and weapon code as players (no cheating), at any server tick rate.

Uneven teams

  • Team modes: when one team has fewer human players, an intermediate bot joins that team automatically, and leaves when another human evens it out. A bot also gives up its slot when a human joins a full server.
  • Players can vote: pause menu -> VOTE BOTS ON / OFF, or vote a bot difficulty. Press F1 (yes) / F2 (no). Majority of human players decides; votes last 30 s.
  • Hosting: "Balance uneven teams with bots" toggle in the Host Game menu.

Dedicated server

  • quark_server --bots N [--allies N] [--botskill 0-3] [--nobalance]; console commands addbot [a|b] [skill] and kickbots.

Other

  • Scoreboard shows BOT instead of a ping for bots.
  • Protocol version 6.
