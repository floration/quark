Update

quark 0.26.0

Everything that changed in this version, and why.

The full notes for this version are its short notes: that was all that was written then.

  • Servers update themselves. tools/server/install.sh sets up a Linux server as a service: it starts on boot, restarts on crash, and checks for updates every minute.
    • When a new version is out, the server builds it in the background.
    • It waits until no match is being played, says "restarting for an update - rejoin in a few seconds", and comes back on the new version.
    • Mid-match, players get "an update is ready - the server restarts after this match" instead.
  • Vote ranked on or off. In the vote menu, RANKED ON... lets anyone pick a ladder. On a ranked server you get SWITCH LADDER... and RANKED OFF instead.
    • A ranked server refuses bot votes, tourney votes, non-1v1 map votes and map editing, and says why.
    • Hosts get the RANKED tile in CHANGE MODE too, and it applies straight away.
  • Vote to edit the map together on any server. EDIT THE MAP TOGETHER in the vote menu, or EDIT MODE in the host's ESC menu.
    • On a normal server the edits are temporary: you can play the edited map (VOTE: PLAY IT or the host's PLAY MODE), but the file is never touched, and the original comes back when the map changes.
    • SAVE A COPY keeps your own copy of the edited map.
  • Maps redone:
    • Random debris replaced with tidy crate stacks in the wall bays.
    • New corner columns, chair rails and inset wall panels.
    • New tiled floor seams in both directions.
    • Wall lamps light every map.
  • Fixed: leaving a server sometimes opened the map editor. The click on DISCONNECT also landed on the MAP EDITOR button of the main menu that appeared under it. A click that changes screens no longer reaches the next screen.
  • Menu fixes:
    • The vote menu is shorter, and bot options are hidden on ranked servers.
    • The pause menu panel now fits all its buttons.
    • The server list shows [RANKED <ladder>] from the server itself, so it stays right after a vote.
  • The network protocol changed, so servers and clients must both be on 0.26.0.
